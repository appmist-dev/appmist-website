# Assets Directory

Store all website assets here.

Suggested organization:

- `logo/` for brand marks, favicon source files, and exported logo assets
- `icons/` for reusable SVG icon files
- `images/` for illustrations, background graphics, and Open Graph images
- `screenshots/` for framed app screenshots and product visuals
- `fonts/` for any locally hosted font files if the project later moves away from Google Fonts
