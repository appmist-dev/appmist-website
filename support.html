How Can We Help You?

Configure app permissions, resolve settings lockouts, and manage your screen-time handoff details.

1. Accessibility Permission Configuration

Android requires system Accessibility privileges so TimeUp Lock can programmatically initiate device lock procedures when your timer runs out. Configure this setting through the following steps:

  • 1

    Tap Settings Redirect

    Open the app and tap the Accessibility Service preference item to go directly to system settings.

  • 2

    Open Installed Services

    Scroll to find Installed Apps, Downloaded Apps, or Accessibility Services.

  • 3

    Activate TimeUp Lock

    Select TimeUp Lock from the list, toggle the service switch to On, and allow system permissions.

2. Display Over Other Apps (Overlay Permission)

To successfully render the lock screen on top of active games, videos, or browsers, the application requires the Draw/Display Over Other Apps permission:

  • 1

    Open Overlay Permission Settings

    Select Overlay Permission inside the TimeUp Lock settings or setup dashboard menu.

  • 2

    Locate TimeUp Lock

    Find TimeUp Lock in the system list of apps permitted to draw overlays.

  • 3

    Enable Draw Option

    Toggle the Allow display over other apps switch to Enabled.

Troubleshooting FAQ

The phone did not lock when the timer reached 0. What is wrong?

This typically occurs if either the Accessibility Service or the Display Over Other Apps permission is disabled. Please verify that both switches are toggle-active in the app dashboard setup menu.

My child bypassed the timer by closing the application.

TimeUp Lock relies on a background service powered by native system alarms. For maximum protection, go to Settings inside the app, select Change PIN, and configure a parent passcode. Once set, a PIN is required to close the timer, stop countdowns, or adjust app configurations.

How do I reset my parent security PIN if forgotten?

When setting up security settings, you will configure a recovery question (for example, "What is your birth year?"). If locked out, tap the recovery options link on the security screen, enter the correct recovery answer, and follow instructions to reset the passcode.
