# 10. Featured App

## TimeUp Lock

Purpose

TimeUp Lock helps parents safely lend their phone to children.

The parent sets a timer before handing over the device.

When the timer expires, the phone automatically locks.

Only the device owner can unlock it using the existing Android security method such as PIN, Pattern, Password or Biometrics.

The app intentionally focuses on one problem and solves it well.

- collect location
- collect photos
- collect messages
- collect passwords
- collect browsing history
- track users
- display advertisements
- sell personal data

Accessibility Service

The Accessibility Service permission is used solely to detect when the countdown timer finishes and trigger the Android lock screen.

Accessibility information is never collected, transmitted or stored.

All app data remains on the user's device.
