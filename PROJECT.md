# Appmist Website Project

# Project Overview

Appmist is an independent Android app studio focused on creating simple, privacy-first applications that solve everyday problems.

The goal of this website is to introduce the Appmist brand, showcase published apps, provide Google Play–compliant legal pages, and serve as the official destination linked from every Play Store listing.

This is not a SaaS website, an agency website, or an e-commerce platform. It is a professional product website for an app publisher.

# Current Product

## TimeUp Lock

TimeUp Lock is a simple parental control and phone handoff application.

Parents can set a timer before handing their phone to a child or another person.

When the selected time expires, the phone automatically locks and requires the parent's PIN to unlock.

The app helps avoid screen-time arguments while giving parents confidence when sharing their device.

### Core Features

* Quick timer presets
* Custom timer durations
* Automatic screen lock
* Parent PIN protection
* Background operation
* Lightweight
* Privacy-first
* Simple interface

# Project Principles

Every design or development decision should answer:

* Does this make the website simpler?
* Does this improve the user experience?
* Does this support the Appmist brand?
* Does this help users trust the apps?
* Does this keep the website lightweight?

If the answer is no, the feature should not be added.
