# About Appmist

Appmist is an independent Android app studio.

Our mission is to build simple, lightweight, privacy-first Android applications that solve everyday problems.

We do NOT build overly complicated apps.

We believe:

* Simplicity over complexity
* Speed over bloat
* Privacy over tracking
* Useful over trendy

Every decision should reflect these principles.

# Current App

TimeUp Lock

Description

TimeUp Lock is a simple parental control and phone handoff app.

Parents can start a timer before handing over their phone.

When the timer expires, the phone automatically locks and requires the parent PIN.

The app is lightweight, privacy-first and designed to eliminate screen-time arguments.

# AI Instructions

Whenever asked to build or modify this project:

1. Read this file first.
2. Follow these rules exactly.
3. Maintain consistency across all pages.
4. Do not introduce frameworks.
5. Keep the website simple, fast and maintainable.
6. Prefer reusable components.
7. Do not remove existing branding unless instructed.
8. If unsure, choose the simpler solution.
9. Every change should improve the user experience.
10. Think like a senior frontend engineer and product designer before writing code.
